## Image Optimization Guidelines

Before placing images in production:
1. Compress all JPEGs to 85% quality or less
2. Use WebP format for better performance where possible
3. Ensure hero.jpg is under 200KB when compressed
4. All images should have descriptive `alt` attributes in the code (already done)

- Always prefer real project photos over stock photography for authenticity and local SEO
